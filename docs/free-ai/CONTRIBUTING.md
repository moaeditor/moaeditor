# 고치는 방법 (How to contribute)

## 한국어

1. 조건이 바뀐 곳, 빠진 곳, 틀린 곳을 [이슈](https://github.com/moaeditor/moaeditor/issues/new/choose)로 알려 주세요.
2. **공식 문서 주소**를 꼭 함께 적어 주세요. 블로그나 커뮤니티 글만으로는 고치지 않습니다.
3. 목록에 넣는 기준
   - 코딩에 쓸 수 있어야 합니다 (OpenAI 호환 주소를 내거나, 코딩 도구로 쓸 수 있음).
   - 돈을 내지 않고 시작할 수 있어야 합니다 (계속 무료, 무료 요금제, 가입 크레딧, 내 PC 실행).
   - 각 회사의 약관을 지켜서 쓰는 방법만 넣습니다. 계정을 여러 개 만들거나 한도를 피해 가는 방법은 넣지 않습니다.
4. 확인된 내용은 다음 확인 때 날짜와 함께 반영합니다.

## English

1. Open an [issue](https://github.com/moaeditor/moaeditor/issues/new/choose) for anything that changed, is missing, or is wrong.
2. **Include a link to the official page.** Blog or forum posts alone aren’t enough.
3. What gets listed
   - Usable for coding (an OpenAI-compatible endpoint, or a coding tool).
   - Free to start (ongoing free tier, free plan, sign-up credit, or runs locally).
   - Only use that follows each provider’s terms. No multiple accounts or ways around limits.
4. Confirmed changes go in with the next check date.
